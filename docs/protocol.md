# 神牛 X3 Pro BLE 通信协议规范（v1.1）

> 来源：神牛官方 Android App（`com.linking.godoxflash` v1.1.1）DEX 反编译分析 + 实机抓包回包比对校验。

## 1. 物理层与 GATT 服务架构

- **设备广播名**：`GDBH-XXXX`（XXXX 为 MAC 地址后 4 位十六进制，例如 `GDBH-E601`）
- **SoC 芯片平台**：Silicon Labs EFR32（蓝牙透传 GATT 模式，非 Mesh）
- **调参控制服务 (Service FEC0)**：`0000fec0-0000-1000-8000-00805f9b34fb`
  - **写入特征值**：`0000fec7-0000-1000-8000-00805f9b34fb`（Write with response, `WRITE_TYPE_DEFAULT`）
  - **回包通知特征值**：`0000fec8-0000-1000-8000-00805f9b34fb`（Notify）
- **触发与同步服务 (Service FFF0)**：`0000fff0-0000-1000-8000-00805f9b34fb`
  - **写入特征值**：`0000fff1-0000-1000-8000-00805f9b34fb`（Write without response）
  - **通知特征值**：`0000fff4-0000-1000-8000-00805f9b34fb`（Notify）

## 2. 全局设置与频道/造型灯数据帧 (A0 帧)

写入通道：`0000fec7`，固定长度 14 字节。

| 字节位置 | 字段名称 | 类型 | 说明 |
|---|---|---|---|
| Byte 0 | 帧头 (Header) | uint8 | 固定为 `0xF0` |
| Byte 1 | 命令字 (Command) | uint8 | 全局控制器命令，固定为 `0xA0` |
| Byte 2 | 负载长度 (Length) | uint8 | 固定为 `0x0A` (10 字节) |
| Byte 3 | 无线频道 (Channel) | uint8 | `0x01` ~ `0x20` (CH 1 ~ CH 32) |
| Byte 4 | 全局提示音 (Sound) | uint8 | `0x01`=开启, `0x00`=关闭 |
| Byte 5 | 全局造型灯 (Lamp) | uint8 | `0x01`=开启, `0x00`=关闭 |
| Byte 6 | 全组统一升降 (ALL Adjust) | uint8 | `0x00`=无, `0x01`=+0.1, `0x81`=-0.1, `0x03`=+0.3, `0x83`=-0.3, `0x0A`=+1.0, `0x8A`=-1.0 |
| Byte 7 | 频闪开关 (Strobo) | uint8 | `0x01`=开, `0x00`=关 |
| Byte 8 | 频闪次数 (Times) | uint8 | 频闪闪光次数 |
| Byte 9 | 频闪频率 (Hz) | uint8 | 频闪闪光赫兹 |
| Byte 10 | 频闪功率 (Power) | uint8 | `100 - decimalPower` |
| Byte 11 | 待机/休眠 (Standby) | uint8 | `0x01`=待机, `0x00`=唤醒正常 |
| Byte 12 | 无线 ID (Wireless ID) | uint8 | `0x00`=关闭, `0x01`~`0x63` (ID 01~99) |
| Byte 13 | 校验码 (CRC8) | uint8 | Byte 0 到 Byte 12 的 Dallas/Maxim CRC8 校验 |

**引闪器回包**：在 `0000fec8` 返回 `F0 A0`。

## 3. 单组调参数据帧 (A1 帧)

写入通道：`0000fec7`，固定长度 11 字节。

| 字节位置 | 字段名称 | 类型 | 说明 |
|---|---|---|---|
| Byte 0 | 帧头 (Header) | uint8 | 固定为 `0xF0` |
| Byte 1 | 命令字 (Command) | uint8 | 单组调参固定为 `0xA1` |
| Byte 2 | 负载长度 (Length) | uint8 | 固定为 `0x07` (7 字节) |
| Byte 3 | 组别 (Group Index) | uint8 | `0x00`=A, `0x01`=B, `0x02`=C, `0x03`=D, `0x04`=E |
| Byte 4 | 工作模式 (Mode) | uint8 | `0x00`=M(手动), `0x01`=TTL, `0x02`=Multi(频闪), `0x03`=OFF(关闭) |
| Byte 5 | 功率值 (Power) | uint8 | 计算公式：`100 - decimalPower` (TTL 模式填 `0x32`) |
| Byte 6 | 造型灯亮度 (Lamp Level) | uint8 | 0-100 百分比，PROP 模式填 0 |
| Byte 7 | 组蜂鸣提示音 (Sound) | uint8 | `0x01`=开启, `0x00`=关闭 |
| Byte 8 | 造型灯模式 (Lamp Mode) | uint8 | `0x00`=关闭, `0x01`=PROP, `0x02`=百分比 |
| Byte 9 | TTL 曝光补偿 (FEC) | uint8 | M 模式填 0；TTL 模式 -30~+30 (0 为 0EV) |
| Byte 10 | 校验码 (CRC8) | uint8 | Byte 0 到 Byte 9 的 Dallas/Maxim CRC8 校验 |

**引闪器回包**：在 `0000fec8` 返回 `F0 A1`。

## 4. 功率双重表达映射表（分母表达式 vs 数字表达式）

神牛 X3 Pro 支持「分母表达法（分数）」与「数字表达法（10分制/十进制步进）」，两者完全一一对应：

| 分母表达法 (Fraction) | 数字表达法 (Decimal) | 内部 dec_val | 发送字节 (`100 - dec_val`) |
|---|---|---|---|
| **1/1 (全功率)** | **10.0** | 100 | `0x00` |
| 1/1 - 0.3 (1/2 + 0.7) | 9.7 | 97 | `0x03` |
| 1/1 - 0.7 (1/2 + 0.3) | 9.3 | 93 | `0x07` |
| **1/2** | **9.0** | 90 | `0x0A` |
| 1/2 - 0.3 | 8.7 | 87 | `0x0D` |
| 1/2 - 0.7 | 8.3 | 83 | `0x11` |
| **1/4** | **8.0** | 80 | `0x14` |
| 1/4 - 0.3 | 7.7 | 77 | `0x17` |
| 1/4 - 0.7 | 7.3 | 73 | `0x1B` |

## 5. 试闪指令 (Test Fire)

- 写入通道：`0000fff1`
- 内容：`f"{(当前时间戳毫秒 - 1483228800000)},Test"`
- 回包通知：`0000fff4` 返回 `1281013`
