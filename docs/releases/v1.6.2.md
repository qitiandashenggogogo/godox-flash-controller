# v1.6.2 版本显示与更新提醒

- 控制台显示当前版本；后台发现新版后，菜单栏出现橙色提示点，版本号旁提供更新入口。
- 点击更新并确认一次安装后，自动下载、验证签名、安装并重启；保留已有更新偏好与用户预设。
- 修复蓝牙授权归属与后端启动生命周期，使用动态端口、实例锁和启动就绪握手，改善重复启动与退出清理。
- 更新重启后，仅尝试恢复更新前确实连接的原设备；恢复记录有版本校验、过期时间和一次性消费限制。

本包包含内置后端，无需安装 Python 或 AI 工具，支持 Apple Silicon 与 Intel Mac。版本为 1.6.2，构建号为 8。

已通过 93 项测试、双架构编译以及本机隔离的签名更新与自动重启验证。真实同事机器和蓝牙设备升级后重连尚未实测。

已安装包含更新器的 v1.6 可通过“检查更新…”升级；更早的不含更新器版本需手动安装一次。橙点提示从本版开始提供。当前沿用自签 Godox Dev 证书，首次跨机安装可能需要在 macOS 中手动放行。
